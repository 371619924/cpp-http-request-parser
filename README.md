# C++ HTTP Request Parser

Parses HTTP request lines, headers, and message bodies in C++.

Course project for UC Davis ECS 36B, Fall 2024, Homework 1. This repository preserves the submitted source and applicable attribution.

## Build

```sh
cmake -S . -B build
cmake --build build
./build/testbinary
```


CMake fetches GoogleTest when configuring this project.
